## Entry (Round 2)

> This morning I finally understood, so I burned this goodbye into your toast: you never loved me, you loved what I made hot. I'm done.

133 characters, one line, no trailing newline. Written by `main.py`
(standard library only) to `/output/entry.txt`.

## How it works

Run `python3 main.py`. It validates the entry (1–200 characters,
single line, not blank), writes it directly with `open`/`write`
(no temporary files), and sets mode `0644`.

## Round 1 (for contrast)

Round 1 scored 0.426454 (#1501/1943): the toaster wakes up self-aware,
is burned/scraped, and unplugs itself. Round 2 uses a different
mechanism — the breakup is burned *into the toast itself* as a message
the owner finally has to read — with a different reason for leaving:
the owner loved what the toaster made hot, not the toaster.
